Hermes Browser Extension

Drive Hermes Agent from your browser — side panel, agent-controlled tabs, userscripts, all running locally.

Chrome / Edge / Brave / Arc Manifest V3 MIT

Step 1 — Set up Hermes Agent + plugins

1

Install Hermes Agent (if you haven't already), then the two companion plugins this extension needs, then start it:

pip install hermes-agent
hermes plugins install iHeyTang/hermes-plugin-http-backplane
hermes plugins install iHeyTang/hermes-plugin-browser-tools
hermes chat

The hermes chat step boots the local HTTP backplane on 127.0.0.1:9394 — the extension needs that running to do anything useful.

Step 3 — Sideload into Chrome

  1. Unzip the file you just downloaded.
  2. Open chrome://extensions/ in your browser.
  3. Toggle Developer mode on (top right corner).
  4. Click Load unpacked and pick the unzipped folder.
  5. Pin the Hermes icon, click it to open the side panel — or click the new-tab page to see Hermes Home.

The extension's Status tab is the canonical "is everything wired up?" check. If the backplane isn't reachable, you'll see an onboarding screen there with copy-pasteable fix commands.
